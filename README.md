# Vrinda Store Sales Dashboard (Excel) </br>

An interactive, single-page Excel dashboard that analyzes sales for Vrinda Store, an online fashion retailer. I built it while learning from Saltish Dheweri's tutorial. </br>

## Key Insights </br>
- Women account for 69% of sales; men for 31% </br>
- Young customers form the largest age group, led by young women </br>
- 92% of orders were delivered; cancelled, returned and refunded orders make up about 8%</br>
- Top channels: Amazon (36%), Myntra (23%), Flipkart (22%)</br>
- Top 5 states by sales: Maharashtra, Karnataka, Uttar Pradesh, Telangana, Tamil Nadu</br>
- Sales peak in March and fall toward the end of the year</br>

## Dashboard Components</br>
- Orders vs Sales (combo chart)</br>
- Men vs Women (pie chart)</br>
- Order Status (pie chart)</br>
- Sales by Channel (pie chart)</br>
- Top 5 States by Sales (bar chart)</br>
- Sales by Age Group and Gender (column chart)</br>
- Monthly Sales Trend (column chart)</br>

## Features</br>
- Slicers for Category, Channel and Month</br>
- Pivot Tables and Pivot Charts linked to one dashboard sheet</br>
- All charts update together when a filter is applied</br>
